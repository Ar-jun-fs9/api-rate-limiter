Key Features

Everything you need to control API usage and prevent abuse

Per-API Key Limits

Each API key has its own request quota. Generate multiple keys for different clients with individual rate limits.

Per-Endpoint Limits

Different endpoints can have different rate limits. Sensitive endpoints like login can have stricter controls.

Redis Backend

Uses Upstash Redis for blazing fast, distributed rate tracking. Accurate counter with 60-second window.

Response Headers

Every response includes X-RateLimit-Limit and X-RateLimit-Remaining headers for quota monitoring.

401 & 429 Errors

Proper HTTP status codes: 401 for auth failures, 429 when rate limit exceeded.

60s Window

Sliding window counter resets every 60 seconds. Automatic quota restoration.

Manual Verification

How to verify rate limiting is working correctly

Without API Key

Send request without X-API-Key header

Expected: 401

Invalid API Key

Send request with fake UUID

Expected: 401

Valid Request

With valid key under limit

Expected: 200 + Headers

Over Limit

Make 10+ requests quickly

Expected: 429

Use Cases

Real-world scenarios where this rate limiter shines

SaaS Applications

Control API usage for different subscription tiers. Free tier gets 100 req/min, Pro gets 1000 req/min, Enterprise gets unlimited.

Bot Protection

Prevent aggressive scraping or bot abuse by limiting request rates per client. Protects your backend from overload.

Mobile Apps

Throttle API calls from iOS/Android clients. Track per-device usage with unique API keys.

Third-Party Integrations

Give external partners limited API access with custom rate limits. Revoke keys instantly if abuse is detected.

Testing & Development

Simulate production rate limiting in staging. Test how your client handles 429 responses and header parsing.

API Monetization

Offer paid API access with tiered rate limits. Charge based on allowed requests per minute.
