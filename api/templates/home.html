Key Features

Everything you need to control API usage and prevent abuse

Per-API Key Limits

Each API key has its own request quota. Generate multiple keys for different clients with individual rate limits.

Per-Endpoint Limits

Different endpoints can have different rate limits. Sensitive endpoints like login can have stricter controls.

Redis Backend

Uses Upstash Redis for blazing fast, distributed rate tracking. Accurate counter with 60-second window.

Response Headers

Every response includes X-RateLimit-Limit and X-RateLimit-Remaining headers for quota monitoring.

401 & 429 Errors

Proper HTTP status codes: 401 for auth failures, 429 when rate limit exceeded.

60s Window

Sliding window counter resets every 60 seconds. Automatic quota restoration.

Local Setup

Get the project running on your machine

Quick Start Guide

1

Clone & Setup

git clone, create venv, pip install

2

Configure Redis

Get REDIS_URL from Upstash, add to .env

3

Run Migrations

python manage.py migrate

4

Create API Key

createsuperuser, go to admin, create key

5

Start Server

python manage.py runserver

Environment Variables 

# .env file
REDIS_URL="rediss://default:password@your-instance.upstash.io:6379"

Get REDIS_URL

Get REDIS_URL from the Upstash Redis dashboard.
